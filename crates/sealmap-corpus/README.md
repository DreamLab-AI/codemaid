# sealmap-corpus

Projects a sealmap Codebase into a contract-enforced 1:1 corpus of dense Mermaid diagrams with LLM-ready metadata.

Part of the [sealmap](../../README.md) workspace. Full API documentation is in the crate rustdoc (`cargo doc -p sealmap-corpus --open`).
