# sealmap-rust

Pure-Rust (syn) frontend for sealmap: extracts symbols, relations and ordered call flows from Rust workspaces.

Part of the [sealmap](../../README.md) workspace. Full API documentation is in the crate rustdoc (`cargo doc -p sealmap-rust --open`).
