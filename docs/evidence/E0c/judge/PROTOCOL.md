# E0c endpoint 4 judging protocol

Generated by `e0 e0c`. Do not edit. Follows E0's `judge/PROTOCOL.md` with the question narrowed by `docs/evidence/E0c/PREREG.md`.

Pairs are (commit, topic) flagged by T_file^seq but not T_flow, drawn only from commits whose parent is the topic's stamp or a descendant of it (amendment #1).

1. Each `<id>.prompt.md` is given, unchanged, to a fresh Claude subagent with no other context. Its reply (one JSON object) is saved as `<id>.j1.json`.
2. Every pair whose first verdict is `yes` is given, unchanged, to a second fresh subagent, independent of the first (it does not see the first verdict). Its reply is saved as `<id>.j2.json`.
3. A pair is a **hidden change** when both judges answer `yes`. A first `yes` the second judge does not confirm counts as not hidden.
4. `e0 e0c-score --out docs/evidence/E0c` computes the hidden-change rate per stratum and pooled, with the Wilson 95% upper bound, and writes `endpoint4.json` and `ENDPOINT4.md`. **Success:** pooled rate ≤ 10%. Fewer than 20 eligible pairs: underpowered, not passed.

The judge must not be the context that drew the sample or wrote the harness. `line_anchors_only` is recorded and not scored.
